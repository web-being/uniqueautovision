# Archived originals (uncompressed)

Original JPEG/PNG source images that were superseded by optimized **AVIF/WebP**
versions served from `assets/images/`. These are kept here for reference /
re-conversion only and are **excluded from the Jekyll build** (see
`exclude:` in `_config.yml`), so they are never published to the site.

They are NOT referenced by any page, CSS, or JS.

Do not add new files here expecting them to be served — they will not be.
